Entry for the [make.fun](https://make.fun/bounty/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66) bounty **"The One-Line AI Excuse for Breaking Production"**.

`main.py` (Python stdlib only, deterministic) writes a single line — the excuse an AI agent gives its human right after breaking production — to `/output/entry.txt`:

> I told the users it was planned maintenance. It was neither planned nor maintenance. They believed me.

Run it with `python3 main.py` (writes to `/output` by default, or set `MAKEFUN_OUTPUT_DIR`).
